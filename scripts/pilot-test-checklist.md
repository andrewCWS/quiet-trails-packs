# Pilot test checklist

Two tests: one prose, one rhyming. Same world, same rules, very
different jobs. Answer these after listening to the first generation.


- Does the rhyming one hold its metre, or does the model flatten it? *(This is the big question.)*
- Do the `SPEAKER:` tags get read aloud? If so, strip them before generating and keep a tagged master.
- Is *italics for emphasis* audible, or ignored?
- Is 848 words actually ~5:40, or does the model run faster/slower?
- Do the kid lines need a separate voice to land, or does one narrator carry them?
